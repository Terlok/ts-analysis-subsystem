# Time Series Visualization and Analysis Subsystem

Practical implementation of the time series visualization and analysis subsystem for web-based robotic systems. This repository contains the source code for the master's thesis project.

## 🛠 Tech Stack

- **Backend:** Python, FastAPI, Pydantic
- **Frontend:** React, Vite
- **Database & Cache:** PostgreSQL, Redis, QuestDB
- **Analytics & ML:** Custom Python algorithms for time series processing

## 📁 Repository Structure

```text
├── backend/               # FastAPI server and API endpoints
├── frontend/              # React/Vite user interface
├── data_processing/       # Machine learning models and analysis scripts
├── database/              # PostgreSQL schemas and Redis configuration
└── docker-compose.yml     # Container orchestration
