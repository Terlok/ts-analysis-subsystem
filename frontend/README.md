# Frontend підсистеми

React 19 + Vite + TypeScript. Графіки малюються на Canvas (uPlot). Мережевий обмін і розбір
JSON виконуються у Web Worker. Масиви точок не зберігаються в стані React (п. 1.5.4 дисертації).

## Запуск

```bash
cd frontend
npm install          # один раз; лише завантаження пакетів, без audit/fund/update-notifier (.npmrc)
npm run dev          # http://127.0.0.1:5173
```

Бекенд має працювати на `127.0.0.1:8000` (`backend/run_dev.sh`). Dev-сервер Vite слухає лише
`127.0.0.1` і передає `/api` та `/ws` на бекенд, тому браузер працює з одним локальним
джерелом. Інша адреса бекенду задається так: `TSA_BACKEND=127.0.0.1:8001 npm run dev`.

Продакшн-збірка: `npm run build`, результат у `dist/`.

Посилання з параметрами відкриває потрібний вигляд у новому вікні:
`/?channels=A,B&window=3` (живий режим, вікно 3 год) або `/?channels=A&from=<с>&to=<с>` (архів).

## Інтерфейс

| Елемент | Що робить | API |
|---|---|---|
| «Вікно 1», «+» | незалежні робочі простори: набори датасетів і налаштування, зберігаються в браузері | — |
| «Дані завантажено (N)» | стан завантаження | — |
| «Вікно: 0.5г…24г» | ширина живого вікна; в архіві — довжина інтервалу | `/api/series`, `/ws/stream` |
| «WS: онлайн» | стан живого потоку, L — затримка від приймання на сервері до браузера | `/ws/stream` |
| «Архів», «▶ Наживо» | ретроспективний перегляд і повернення до живого потоку | `/api/series` |
| QuestDB / PostgreSQL / Redis | стан сховищ | `/api/health` |
| Канал, «Додати», чипи | вибір датасетів | `/api/channels`, `/api/channels/state` |
| «з / по», ◀ ▶ | інтервал архіву, панорамування | `/api/series` |
| події / позначки / тривоги | шари поверх графіка: епізоди, точки повної роздільності, тривоги | `/api/series` (events, flags, alarms) |
| «Один / Окремі» | один графік або окремий для кожного датасету із синхронним курсором | — |
| «⚑ Мітка» | мітка в позиції курсора (режим, коментар) | `/api/modes` |
| «Скинути» | скидання масштабу (також подвійний клік по графіку) | — |
| Графік | виділення — масштаб; колесо — масштаб; Shift+колесо — панорамування | `/api/series` |
| Підказка біля курсора | значення, прогнози порівнюваних моделей і залишки, епізоди, позначені точки (залишок проти порогу, заміна), тривоги, мітки | — |
| Смуга під графіком | огляд усього архіву каналів; рамку можна перетягувати | `/api/channels/stats`, `/api/series` |

Вкладки нижньої панелі:

| Вкладка | Вміст | API |
|---|---|---|
| Статистика датасетів | межі осі Y, мін / макс / сер / точок / джерело / η, останнє значення | `/api/series`, `/api/channels/state` |
| Події | епізоди аномалій і викидів; клік показує контекст події на графіку | `/api/events`, `/api/events/{id}` |
| Тривоги | активні тривоги з квитуванням, журнал, редактор правил | `/api/alarms`, `/api/alarms/log`, `/api/alarms/{id}/ack`, `/api/alarms/rules` |
| Первинні дані | значення, коди якості, nd/otkl, діагностика точки, експорт CSV | `/api/raw`, `/api/flags` |
| Аналіз | прогін діагностики з іншими параметрами на видимому інтервалі; порівняння двох моделей (A і B) з прогнозами на графіку | `/api/analysis/preview` |
| Канали | реєстр тегів: метадані, параметри аналітики, реєстрація, видалення | `/api/channels`, `/api/channels/stats` |
| Моделі | навчання (бустинг / ліс / лінійна), картка моделі з перевіркою на тестовій частині, активація, видалення | `/api/models…`, `/api/models/train`, `/api/models/jobs` |
| Система | затримки К1, навантаження ρ = λτ (К2), черги, кеш тайлів і пам'ять Redis (К6), параметри сервера | `/api/metrics`, `/api/config`, `/api/health` |

`/api/ingest` і `/ws/ingest` використовує відтворювач `backend/scripts/replay.py`, а не інтерфейс.

## Як влаштовано

- `src/lib/engine.ts` — `DataEngine`: масиви точок поза React.
  - **Живий режим:** історія вікна з `/api/series` (періодично оновлюється) плюс фіналізовані
    точки й «хвіст» з `/ws/stream`.
  - **Архів:** масштабування одразу перемальовує вже завантажені дані, а через 120 мс
    дозапитує детальніші (прогресивне уточнення).
- `src/workers/data.worker.ts` — `fetch` і WebSocket. Відповіді перетворюються на
  `Float64Array` і передаються в основний потік без копіювання.
- `src/chart/TimeChart.tsx` — графік uPlot: окрема шкала Y на кожен датасет, синхронний курсор.
- `src/chart/overlays.ts` — шар подій. Позначки малюються в точних позиціях незалежно від
  ступеня проріджування кривої (формула 1.16).
- `src/chart/Navigator.tsx` — оглядова смуга з рамкою видимого інтервалу.
